# تحلیل‌گر داده های معاملاتی و بک تست

این پروژه یک ابزار خط فرمان برای تحلیل داده‌های معاملاتی است. داده‌ها شامل تاریخ، موقعیت (Position) و استراتژی (Strategy) هستند. برنامه با خواندن یک فایل اکسل، تحلیل‌های مختلفی مانند نرخ برد، تعداد پاداش‌ها، حداکثر برد/باخت متوالی و ... را انجام می‌دهد و نتیجه را در کنسول و یک فایل متنی ذخیره می‌کند.

## پیش‌نیازها
- پایتون 3.6 یا بالاتر
- کتابخانه‌های `pandas` و `numpy`

نصب کتابخانه‌ها:
```bash
pip install pandas numpy
```

## فایل‌های پروژه
- `run.py`: فایل اصلی اجرای برنامه. مسئول دریافت ورودی، مدیریت فایل‌ها و نمایش خروجی‌ها است.
- `analyzer.py`: شامل توابع تحلیل داده‌ها (محاسبه نرخ برد، تعداد پاداش‌ها، برد/باخت متوالی و ...).
- `dataset_maker.py`: تولید یک دیتاست نمونه (`my_dataset.csv`) برای تست برنامه.
- `SAVED_ADDRESS.txt`: (اختیاری) آخرین آدرس فایل اکسل ذخیره شده را نگه می‌دارد.
- `Analyze_For_You.txt`: فایل خروجی که نتایج تحلیل در آن ذخیره می‌شود.
- `your_dataset.csv`: فایل موقت تبدیل اکسل به CSV که پس از اجرا حذف می‌شود.
- `my_dataset.csv`: دیتاست نمونه تولید شده توسط `dataset_maker.py`.

## نحوه اجرا
```bash
python run.py
```

پس از اجرا، برنامه از شما آدرس یک فایل اکسل (`.xlsx`) را می‌پرسد. این فایل باید حداقل شامل دو ستون `position` و `strategy` باشد. ستون `date` اختیاری است.

اگر فایل اکسل پیدا نشود، برنامه از شما می‌پرسد که آیا می‌خواهید از دیتاست نمونه استفاده کنید. با وارد کردن `Y`، دیتاست نمونه ساخته شده و تحلیل روی آن انجام می‌شود.

اگر قبلاً آدرسی ذخیره شده باشد، برنامه به شما اجازه می‌دهد با وارد کردن `O` همان فایل قبلی را دوباره تحلیل کنید.

## تحلیل‌های انجام شده
برنامه به ترتیب و با تأیید شما (فشار دادن Enter) تحلیل‌های زیر را انجام می‌دهد:

1. **تعداد کل معاملات به تفکیک استراتژی**: تعداد معاملات هر استراتژی را نشان می‌دهد.
2. **تعداد پاداش‌ها**: تعداد هر موقعیت (SL و TP1 تا TP20) و مقدار پاداش (تعداد × اندیس) را محاسبه می‌کند.
3. **نرخ برد با تی‌پی‌های بهینه**: تی‌پی بهینه بر اساس بیشترین پاداش انتخاب می‌شود و نرخ برد برای آن محاسبه می‌شود.
4. **نرخ برد هر استراتژی با TP1**: برای هر استراتژی، تعداد SL، تعداد TP و نرخ برد را محاسبه می‌کند.
5. **حداکثر بردهای متوالی**: بیشترین تعداد TP متوالی را پیدا می‌کند.
6. **حداکثر باخت‌های متوالی**: بیشترین تعداد SL متوالی را پیدا می‌کند.

خروجی همه این تحلیل‌ها در کنسول نمایش داده شده و در فایل `Analyze_For_You.txt` ذخیره می‌شود.

## فرمت فایل ورودی
فایل اکسل باید شامل ستون‌های زیر باشد:
- `position`: موقعیت معامله. مقادیر مجاز: `SL`, `TP1`, `TP2`, ..., `TP20`.
- `strategy`: نام استراتژی. (در دیتاست نمونه: `A` تا `H`)

ستون `date` اختیاری است و در تحلیل‌ها استفاده نمی‌شود.

## دیتاست نمونه
برای تست سریع، می‌توانید از دیتاست نمونه استفاده کنید. این دیتاست به صورت تصادفی با تاریخ‌های سال 2026 و موقعیت‌ها و استراتژی‌های تصادفی ساخته می‌شود. برای ساخت آن، کافی است در پاسخ به سوال استفاده از دیتاست نمونه، `Y` وارد کنید.

## نکات
- پس از پایان تحلیل، برنامه می‌پرسد که آیا می‌خواهید ادامه دهید یا خیر. با فشردن `C` می‌توانید فایل دیگری را تحلیل کنید، در غیر این صورت برنامه بسته می‌شود.
- فایل `your_dataset.csv` پس از هر اجرا حذف می‌شود.
- در صورت نبود کتابخانه‌های لازم، پیام خطا همراه با دستور نصب نمایش داده می‌شود.
- در صورت نبود فایل‌های اصلی برنامه (`run.py`, `analyzer.py`, `dataset_maker.py`)، پیام خطا نمایش داده شده و برنامه بسته می‌شود.

## ساختار توابع analyzer.py
- `count_strategies(df)`: تعداد هر استراتژی.
- `analyze_win_rate_by_tp1(df)`: نرخ برد هر استراتژی با در نظر گرفتن همه TPها (به عنوان TP1).
- `sort_key(p_r)`: کلید مرتب‌سازی برای موقعیت‌ها.
- `positions_count(df)`: تعداد هر موقعیت.
- `tp_rewards(df)`: محاسبه پاداش هر موقعیت (تعداد × اندیس).
- `optimized_tp(df)`: یافتن تی‌پی بهینه بر اساس بیشترین پاداش.
- `find_andis(position)`: استخراج اندیس از نام موقعیت (مثلاً TP3 → 3، SL → 1).
- `count_best_tps(df)`: تعداد تی‌پی‌های بهینه و بزرگتر از آن.
- `analyze_win_rate_by_best_tp(df)`: نرخ برد بر اساس تی‌پی بهینه.
- `positions_list(df)`: لیست موقعیت‌ها.
- `consecutive_wins(df)`: حداکثر بردهای متوالی.
- `consecutive_losses(df)`: حداکثر باخت‌های متوالی.
